## 🚀 Featured Projects

### 🧠 Sleep Stage Classification

*Automatic sleep stage classification from polysomnography (PSG) signals.*

- **What it does:** Predicts 5 sleep stages (Wake, N1, N2, N3, REM) using a combined XGBoost model (multiclass + binary for N1/N2) with a confidence filter.
- **Key result:** **96.1% accuracy** on high-confidence predictions (50% coverage).
- **Stack:** Python · XGBoost · YASA · MNE · Scikit-learn

[🔗 View repository](https://github.com/Vicctor52/Sleep-Stage-Classification)

### 📈 Financial Sentiment Lab

*Analyzes the presence of popular stocks in social media and news to relate sentiment with market behavior.*

- **What it does:** Ingests stock prices (yfinance) and financial news, scores headlines with FinBERT, aligns them to NYSE trading sessions, and computes daily sentiment indices, log returns, lead-lag correlations and Granger causality tests.
- **Key features:** Automated weekday pipeline via GitHub Actions, Streamlit + Plotly dashboard, exploratory lead-lag and Granger analysis with FDR correction.
- **Stack:** Python · FinBERT (Hugging Face) · yfinance · Streamlit · Plotly · Parquet · GitHub Actions

[🔗 View repository](https://github.com/Vicctor52/Stock-Sentiment-Analysis)
