## 🚀 Proyectos destacados

### 🧠 Clasificación de fases del sueño

*Clasificación automática de fases del sueño a partir de señales de polisomnografía (PSG).*

- **Qué hace:** Predice 5 fases del sueño (Wake, N1, N2, N3, REM) mediante un modelo combinado de XGBoost (multiclase + binario para N1/N2) con filtro de confianza.
- **Resultado clave:** **96,1 % de precisión** en predicciones de alta confianza (50 % de cobertura).
- **Stack:** Python · XGBoost · YASA · MNE · Scikit-learn

[🔗 Ver repositorio](https://github.com/Vicctor52/Sleep-Stage-Classification)

### 📈 Financial Sentiment Lab

*Analiza la presencia de acciones populares en redes sociales y noticias para relacionar el sentimiento con el comportamiento del mercado.*

- **Qué hace:** Ingiere precios de acciones (yfinance) y noticias financieras, puntúa los titulares con FinBERT, los alinea con las sesiones bursátiles de NYSE y calcula índices de sentimiento diarios, log-returns, correlaciones lead-lag y tests de causalidad de Granger.
- **Características clave:** Pipeline automatizado entre semana vía GitHub Actions, dashboard en Streamlit + Plotly, análisis exploratorio lead-lag y Granger con corrección FDR.
- **Stack:** Python · FinBERT (Hugging Face) · yfinance · Streamlit · Plotly · Parquet · GitHub Actions

[🔗 Ver repositorio](https://github.com/Vicctor52/Stock-Sentiment-Analysis)
