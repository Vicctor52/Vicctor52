## 🚀 Proyectos destacados

### 🧠 [Clasificación de fases del sueño](https://github.com/Vicctor52/Sleep-Stage-Classification)
*Clasificación automática de fases del sueño a partir de señales de polisomnografía (PSG).*

- **Qué hace:** Predice 5 fases del sueño (vigilia, N1, N2, N3 y REM) usando un modelo combinado de XGBoost (multiclase + binario para N1/N2) con un filtro de confianza.
- **Resultado clave:** **96,1% de precisión** en predicciones de alta confianza (50% de cobertura).
- **Stack:** Python · XGBoost · YASA · MNE · Scikit-learn
